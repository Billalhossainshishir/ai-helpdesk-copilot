## Interview talking points

- Started with the CRUD workflow before adding ML so the core product remained reliable.
- Chose a reproducible classical text-classification baseline rather than hiding logic behind an external API.
- Kept priority deterministic and explainable because business impact should be auditable.
- Used TF-IDF similarity for both knowledge retrieval and resolved-incident matching so evidence is inspectable.
- Built the demo around a 30–60 second recruiter flow with no login and synthetic data.
